# V3 修复与验证

2026-10-12，基于原项目 1.11.4+11104。返回时保留同一播放器和地址，小窗可拖动，缩放后保持在可见区域。切房先停止旧声音，旧画面卸载后释放播放器。

原故障日志记录读流失败、连接重置，随后旧地址返回 HTTP 403。这支持旧地址重试失败的判断，无法确定首次断流来自 CDN、网络设备或地址鉴权，也不能证明固定十分钟到期。

恢复时重新查询状态、清晰度、签名和地址，优先换线。错误和结束事件合并，实际进度恢复才确认成功。30 秒静默卡流触发恢复，用户暂停不会；每次最多 45 秒，连续失败最多三次，稳定播放后重置额度。刷新、换线路和清晰度使旧请求失效。

抖音主播搜索进入官方“用户”页，房间接口失败转官方“直播”页。保留签名、Cookie 和翻页信息，丢弃过期响应。只验证页面加载，未验收登录后完整结果及跳转。

## 验证

- Windows：远程构建的验证程序播放真实公开直播，小窗拖动、边界、搜索标签、提示、暂停和返回通过。返回时同一播放器与地址，新增播放请求为 0。
- 小窗模拟断流重新调用斗鱼接口 3 次并恢复；切房停止并释放旧播放器，关闭后会话清空和播放器释放。FlutterErrors 为空。
- V2 恢复逻辑完成 720 秒公开直播，360 次进度采样均变化；4 次模拟断流均恢复且未误报未开播。不是 V3 再次完成长时测试，不保证任意网络故障都能恢复。

Release 附运行验证、文件清单与 SHA256；不包含用户数据库、Cookie 或签名播放地址。
