# Simple Live 多画面 V4

首页右上角的网格按钮、我的 → 多画面、直播间右上角的「加入多画面」都能进入。

- 支持 2、3、4、9 画面。添加直播会按需要扩大布局；缩小布局前需关闭多余画面，避免看不见的直播仍占用资源。
- 可以从关注列表选择，或选择平台输入房间号，也可以粘贴手机分享文字及直播间链接。支持抖音和 B 站短链，以及斗鱼、虎牙的直播间链接。
- 点每格喇叭切换声音，同一时间只收听一路。顶部喇叭可以全部静音。
- 每格右上角菜单可以暂停、继续、刷新、选择清晰度、放大或关闭。双击画面可放大，再次双击还原；放大时其他直播继续播放。
- 从普通直播间或悬浮小窗进入时，会将当前房间加入第一格，并停止原播放器。返回首页会停止全部多画面；普通直播间原有的小窗功能保留。
- 每路独立检测卡流、重新获取直播地址并换线，采用有限重试。网络请求失败显示连接错误，不据此判断主播下播。达到重试上限后可手动刷新。
- 默认选择平台清晰度列表中间的一档，每路播放缓存最多 16 MiB，降低同时播放多路的开销。视频解码、显存和网络仍随画面数增加；九路播放建议按电脑情况调低清晰度。

抖音主播名搜索沿用 V3 的官方网页入口，官网可能要求登录或验证码。通过公开房间链接添加与主播名搜索是不同入口。

## 使用

退出旧版后，完整解压 `Simple-Live-Windows-x64-V4.zip`，运行 `simple_live_app.exe`。保留 DLL 与 `data` 目录。新旧版本沿用同一份用户设置，请一次只运行一个正式版本。窗口标题为「Simple Live（多画面 V4）」。

## 验证与构建

新增的测试涵盖布局容量、重复添加、唯一声音、快速切换、静音后添加、删除与退出的资源释放、链接解析与短链失败处理。连同 V3 回归测试共 33 项。

Windows 实机验证使用独立的测试配置，实际结果见发布附件 `Windows-runtime-validation.json`。探针源码为 `simple_live_app/lib/testing/multi_live_probe.dart` 和 `mini_player_probe.dart`，仅供开发验证，不是正式版入口。

Dart AOT 和资源在 Debian 上用 Flutter 3.38.10 / Dart 3.10.9 编译。Windows 启动器和插件 DLL 复用已验证的原有运行文件，未重新编译原生插件；没有进行 Android、iOS 或其他桌面平台的二进制验证。
